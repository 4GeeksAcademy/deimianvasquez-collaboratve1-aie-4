# Pagina Vista de Producto

## Requerimientos
- Flex columns

- Image de producto
    - Full width

- Caracteristicas de producto
    - h1 Nombre del producto full width
        - Tamano maximo de altura 3 lineas de texto
        - h2 Codigo de producto: 5 digitos alfanumerico
    - Talla
     - Componente tags en flex row caption text
     - 3 tags: CH M XL
     - Cuando talla no disponible, el borde del tag punteado
        - EL tag con transparencia sutil
    - Precio
        - h3 numero maximo 5 digitos
        - Tamano rem de acuerdo a breakpoint
        - Puede ser en dolares pesos colombianos o mexicanos

    - CAT Agregar al carrito
        - Accion primaria color de acento
        - Debajo del bloque de imagenes y caracteristicas de producto
        - Full width
    - Descripcion de producto
        - Debajo de CAT
        - p full width auto height
        - Acordion Materiales de producto
            - Full width
             - p con materiales de producto
         - Acordion Uso recomendado
            - p full width con recomendaciones de uso de prenda
